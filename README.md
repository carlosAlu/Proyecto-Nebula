# Proyecto Nebula

El repositorio separa la aplicación frontend del espacio destinado al backend:

- `Frontend/`: aplicación React/Vite, código fuente, recursos públicos y configuración npm.
- `Backend/`: espacio para los componentes del backend.

Para iniciar o validar el frontend, entra en `Frontend/` y ejecuta los comandos descritos en [Frontend/README.md](./Frontend/README.md).
